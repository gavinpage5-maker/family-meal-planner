# Family Meal Planner — Version 4.1

Adds:
- Shopping-list ingredient normalisation for capitalisation, common plurals and common unit spellings.
- Add your own recipe form for family/book recipes.
- Website URL import using standard JSON-LD Recipe data when the site allows browser access.
- Paste-text fallback when a recipe site blocks automatic import.

A future version can move website importing to a Supabase Edge Function for more reliable imports from sites that block browser requests.
